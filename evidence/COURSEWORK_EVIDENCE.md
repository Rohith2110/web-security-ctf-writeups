# Coursework Evidence
## Academic Context

This repository is based on practical web application security exercises
completed as part of my MSc Cybersecurity and Machine Learning studies.

The exercises were performed within a controlled and authorised university
cybersecurity laboratory.

## Project Scope

The practical work involved investigating a series of web application
security challenges covering authentication, access control, injection,
information disclosure, token security and hidden-data analysis.

## Practical Work Completed

The project demonstrates hands-on investigation of:

- Hardcoded credentials in client-side JavaScript
- HTTP parameter tampering
- OS command injection
- Information disclosure through exposed resources
- Cookie-based authentication weaknesses
- SQL injection
- LSB steganography
- JWT authentication and authorization weaknesses

## Tools and Techniques

During the exercises, I worked with concepts and tools including:

- Firefox Developer Tools
- HTTP request inspection and modification
- Browser cookies and storage
- JavaScript source inspection
- SQL injection analysis
- Operating-system command injection
- JSON Web Token analysis
- Steganography analysis
- Authentication and authorization testing

## Security Engineering Skills

The coursework helped develop practical understanding of:

- Vulnerability identification
- Root-cause analysis
- Security impact assessment
- Authentication and authorization weaknesses
- Input validation
- Secure application design
- Security remediation
- Defensive detection opportunities

## Defensive Security Relevance

Although the original exercises focused on identifying application
vulnerabilities, this portfolio version also considers how attack activity
could potentially be detected through:

- Application logs
- Authentication logs
- Web-server logs
- Database telemetry
- Endpoint activity
- SIEM correlation

This connects the practical web security work with my broader interests in
Security Analytics, Detection Engineering and Incident Response.
