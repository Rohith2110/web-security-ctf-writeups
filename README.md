# web-security-ctf-writeups
## Overview
This repository documents web application security exercises completed in controlled academic environments.

## Topics Covered
* Cookie Manipulation
* Insecure Direct Object References (IDOR)
* Command Injection
* Path Traversal
* JWT Security Issues
* Web Enumeration
* Input Validation Weaknesses

## Tools Used
* Burp Suite
* Browser Developer Tools
* Linux

## Skills Demonstrated
* Web Application Security
* Vulnerability Assessment
* Security Testing
* HTTP Analysis
* OWASP Top 10 Awareness

## Important Note
All activities were performed in controlled educational environments.
No real systems were targeted.
No flags, secrets, or university solutions are included.
